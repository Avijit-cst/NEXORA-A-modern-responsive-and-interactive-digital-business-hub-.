# NEXORA — Smart Digital Business Hub 🚀

NEXORA is a modern, responsive and interactive **Digital Business Hub** designed to showcase how different types of businesses can manage their digital presence through one powerful interface.

The project focuses on **modern UI/UX, responsive design, smooth animations and interactive JavaScript components**.

## ✨ Features

* 🎨 Modern premium UI design
* 📱 Fully responsive for Desktop, Tablet & Mobile
* 🌓 Dark / Light mode
* 📊 Interactive dashboard
* 🏢 Business type selector
* 📈 Animated statistics & counters
* 🖼️ Dynamic project showcase
* 🔎 Project filtering system
* 💬 Testimonial carousel
* ❓ Interactive FAQ accordion
* 📩 Contact form validation
* 📱 Mobile navigation menu
* 🔝 Back-to-top button
* ✨ Scroll reveal animations
* ⚡ Smooth scrolling
* 🎯 Interactive UI elements

## 🏢 Supported Business Types

The interactive business selector includes:

* Restaurant
* E-commerce
* Salon
* Agency
* Fitness

Each business type dynamically displays relevant dashboard information.

## 🚀 Getting Started

No installation or backend is required.

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/nexora.git
```

### 2. Open the project

Open the project folder in VS Code.

### 3. Run the website

Simply open:

```text
index.html
```

in your browser.

For the best development experience, use the **Live Server** extension in VS Code.

## 🖼️ Customizing Images

You can easily replace the project images from the `images` folder.

Replace:

```text
project-restaurant.jpg
project-store.jpg
project-salon.jpg
project-agency.jpg
project-fitness.jpg
```

with your own project images while keeping the same filenames.
